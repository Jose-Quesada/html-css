# HTML y CSS · Apuntes de interfaces

Material de estudio de **HTML5** y **CSS** elaborado como **apoyo a las clases** de los módulos de interfaces de los ciclos de **DAW** y **DAM** en Andalucía. Todo el contenido está pensado para consultarse junto a las sesiones presenciales: teoría concisa, ejemplos prácticos comentados y ejercicios con solución.

| Módulo | Código | Ciclo | Relación con estos apuntes |
|---|---|---|---|
| Lenguajes de marcas y sistemas de gestión de información | **0373** (LMH) | DAW | HTML5 completo: semántica, formularios, multimedia y estructura. |
| Diseño de interfaces web | **0615** (DIW) | DAW | CSS de principio a fin: maquetación, responsividad y accesibilidad. |
| Desarrollo de interfaces | **0488** (DI) | DAM | Repaso de HTML5/CSS previo al trabajo con frameworks (Angular). |

## Cómo usar este material

!!! note "Conocimientos previos"

    - HTML básico (etiquetas y estructura de documento); el capítulo 01 repasa lo necesario.
    - No hace falta CSS previo: la sección CSS empieza desde cero.

!!! tip "Claves para el examen"

    - Cada capítulo termina con un recuadro **«Claves para el examen»** y contiene **«Error común»** incrustados: son los conceptos que más se evalúan.
    - Los ejercicios de HTML (09) incluyen **criterios de evaluación**; usa las soluciones (10) solo después de intentarlo.
    - Valida siempre tu código en <https://validator.w3.org> y comprueba la accesibilidad con el árbol de accesibilidad de las DevTools.
