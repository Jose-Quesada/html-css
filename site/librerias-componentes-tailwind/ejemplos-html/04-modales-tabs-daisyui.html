Preguntas Frecuentes (FAQ)

Respuestas rápidas a las dudas comunes del curso de desarrollo frontend.

¿Cuál es la diferencia principal entre DaisyUI y Flowbite?

DaisyUI utiliza clases semánticas de CSS puro inyectadas en Tailwind y no requiere JavaScript para componentes como modales o menús. Flowbite mantiene clases utilitarias explícitas de Tailwind y se apoya en un script JavaScript que gobierna atributos data-* y accesibilidad WAI-ARIA.

¿Por qué DaisyUI usa la etiqueta HTML5 <dialog>?

Porque <dialog> es el estándar web oficial de los navegadores. Proporciona aislamiento visual en la capa superior (Top Layer), atrapamiento de foco automático para accesibilidad, oscurecimiento de fondo con ::backdrop y cierre nativo con la tecla Escape.

¿Cómo se entregan las prácticas de interfaces?

Mediante repositorios Git alojados en GitHub o GitLab, asegurando que la consola de desarrollo no presente advertencias y que el HTML sea validado según las directrices del W3C.
